# Вариант 55 — Управление парковкой

Проект подготовлен для практической работы №3.

## Реализованные функции

- бронирование парковочного места;
- освобождение парковочного места;
- просмотр доступности парковочных мест.

## Подходы

- TDD;
- ATDD;
- BDD;
- SDD.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск TDD

```bash
pytest tests/test_tdd.py -v
```

## Запуск ATDD

```bash
pytest tests/test_atdd.py -v
```

## Запуск BDD

```bash
pytest features/test_bdd.py -v
```

## Запуск SDD

```bash
pytest tests/test_sdd.py -v
```

## Итоговый запуск

```bash
pytest -v
```
